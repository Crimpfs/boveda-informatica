Semana 4: Estrategias de Aproximación

El Enjambre Médico

Optimizando rutas de vuelo para drones de rescate médico utilizando la Heurística del Vecino Más Cercano (Nearest Neighbor).

El Problema: Salvar Vidas a Contrarreloj

Imagina un desastre natural que ha dejado a múltiples hospitales de campaña sin suministros críticos. Tienes una flota de drones en la base principal. Tu misión es entregar vacunas a 150 coordenadas diferentes en el menor tiempo posible, regresando a la base antes de que se agote la batería.

🚁

Complejidad Explosiva

Este es el clásico Problema del Viajante de Comercio (TSP). Probar todas las rutas posibles (Fuerza Bruta) con 150 puntos requeriría calcular 150! (factorial) rutas. ¡Tardaríamos más que la edad del universo en encontrar la ruta matemáticamente perfecta!

⏱️

Restricción de Tiempo

En emergencias médicas, no necesitamos la ruta "perfecta" si tardamos días en calcularla. Necesitamos una ruta "lo suficientemente buena" (una aproximación óptima) calculada en milisegundos.

La Estrategia: Heurísticas (Semana 4)

Dado que el problema es NP-Hard, abandonamos las estrategias exactas (como Branch & Bound) y optamos por una Estrategia de Aproximación (Heurística). Usaremos el algoritmo del Vecino Más Cercano (Nearest Neighbor).

1

Inicio desde la Base

El dron arranca motores en la coordenada inicial (Base de Operaciones). Marcamos este nodo como "visitado".

2

Escaneo Radial (Decisión Golosa)

Calculamos la distancia euclidiana hacia todos los hospitales que aún NO han sido visitados. Elegimos el que esté físicamente más cerca de nuestra posición actual.

3

Vuelo y Repetición

El dron vuela a ese punto, lo marca como visitado y repite el Paso 2 desde su nueva ubicación hasta que todos los puntos estén cubiertos. Al final, retorna a la base.

Implementación en Python

El código es sorprendentemente limpio y corre en tiempo O(n²), lo cual es inmensamente más rápido que el tiempo factorial O(n!) de la fuerza bruta.

drone_router.py 
import numpy as np
from scipy.spatial import distance

def nearest_neighbor_heuristic(puntos, inicio=0):
    # puntos: Array de coordenadas (x,y) de los hospitales
    n_puntos = len(puntos)
    visitados = [False] * n_puntos
    ruta = [inicio]
    
    visitados[inicio] = True
    nodo_actual = inicio

    while len(ruta) < n_puntos:
        distancia_min = float('inf')
        vecino_cercano = None
        
        # Buscar el hospital no visitado más cercano
        for i in range(n_puntos):
            if not visitados[i]:
                d = distance.euclidean(puntos[nodo_actual], puntos[i])
                if d < distancia_min:
                    distancia_min = d
                    vecino_cercano = i
                    
        # Volar hacia el vecino más cercano
        ruta.append(vecino_cercano)
        visitados[vecino_cercano] = True
        nodo_actual = vecino_cercano

    # El dron debe volver a la base
    ruta.append(inicio)
    return ruta
